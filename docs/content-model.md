# World Content Model · минимальная модель расширения

**Статус:** проектный контракт, ещё не полноценная схема/реализованная игровая механика. Канон хранится отдельно от исполняемых определений и серверных экземпляров.

## Три уровня

1. **Canon:** утверждённые имена, хронология, факты, запреты (например, девять стихий и характер тьмы).
2. **Definition:** `kind`, `id`, `revision`, `references`, `components`, `required_capabilities` — шаблон (как создать/нарисовать/оживить).
3. **Instance:** `instance_id`, координаты, текущее HP, статус, владелец, версия активной редакции — исключительно серверная БД.

Все связи между definition используют стабильные ID, не локализованные названия. Для исчезающих/переименованных ID требуются миграции. Тексты и диалоги являются недоверенным контентом, не командами AI.

## Планируемые `kind` и ответственность

| Вид | Содержит | Проверяется |
| --- | --- | --- |
| `region` | координаты/сектор, география, seed генератора, соседства, входы/выходы | геометрическая связность, швы, навигация, коллизии |
| `creature` | архетип тела, поведение, способности, награды, визуальные параметры | соответствие доступным генераторам/анимациям/способностям |
| `npc` | персона, репутация/фракция, расписание, взаимодействия | ссылки на фракции и диалоги, достижимость |
| `faction` | история, отношения, репутация | лор, граф отношений, ограничения конфликтов |
| `ability` | action primitive, стихия, эффекты, cooldown/resource | известные серверу эффекты, лимиты, баланс |
| `item` | свойства, слоты, награды, источники | экономика, допустимые статы |
| `quest` | триггеры, условия, шаги, награды | достижимость, невозможность тупиков/бесконечной награды |
| `dialogue` | реплики и ветвления | выполнимые предикаты, локализация и согласованность |
| `event_template` | триггер и разрешённые серверные операции | идемпотентность, scope, budget, TTL |

## 3D ASCII без Blender

`appearance` использует **реестр известных процедурных генераторов** (`humanoid`, `quadruped`, `tree`, `building`, `terrain` и др. — это предложения, не существующие реализации). Для каждого: версия алгоритма, seed, ограниченный набор параметров, привязки анимаций. Невозможный генератор/неизвестный тип поведения → отказ и задача на разработку, **не** самовольная генерация C-кода.

## Генерация региона

Пакет содержит: положение в глобальной системе координат; соседние сектора; terrain/biome spec; точки входа; инфраструктуру путей; набор разрешённых спаунов; объекты интереса; условия доступности. Построитель производит детерминированную геометрию с версией/seed, collision/navmesh (или эквивалент) и связывает границы. Тесты: seam continuity, reachable paths, spawn safety, FPS/budget, события/квесты, серверная геометрия ≈ клиентская.

**Никакая карта мира и схема region-data ещё не утверждена.** Этот контракт описывает, что потребуется реализовать, а не утверждает, что генерация уже работает.

## Контроль лора

Для любой новой записи — `canon_references` (проверяемые факты), предполагаемые последствия, time range и сценарий отката. Противоречие канону → review, а не автоматическое переписывание истории.
