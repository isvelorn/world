# ISVELORN · World

**Канонический источник игровых определений и утверждённого лора.** Технические контракты организации — в [Foundation](https://github.com/isvelorn/.github/blob/main/docs/architecture.md).

## Слои контента

- `canon/` — утверждённые факты о мире, включая известные ограничения магии.
- `data/` — машинно-читаемые определения игровых объектов; формат должен проверяться до доставки на сервер.
- `schemas/` — формальные схемы для сериализованных определений.
- `topics/` — указатель тематических обсуждений, вопросов и решений (пока без утверждения инструмента для обсуждений).
- `tools/` — локальная проверка содержимого; тесты не должны требовать сервера.

Проектирование: [Content Model](docs/content-model.md) · [World Builder](docs/world-builder.md). Машинные определения пока содержат только исходный список стихий; генераторы персонажей и регионов **ещё не реализованы**.

**Контент не равен состоянию:** определение существа не хранит HP конкретной особи; определение региона не хранит положение игрока. Зависимости задаются стабильными ID, без неявных ссылок на произвольные названия.

## Магия

Зафиксирована исходная модель из девяти стихий: 💙 вода, 🤎 земля, ❤️ огонь, 🤍 воздух, 💚 природа, 🩷 электричество, 💛 свет, 🖤 тьма, 🩶 звук. Тьма — самостоятельная сложная и сильная магия, а не отсутствие света. 🩵 холод пока **не утверждён**.

См. [канон магии](canon/magic.md) и [каталог стихий](data/elements.json).

## Статус

На текущем этапе нет готовой карты, конкретных врагов, доказанной визуальной системы или принятого списка квестов. Новая идея не становится каноном, пока явно не подтверждена и не внесена в соответствующий файл.
